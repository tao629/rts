## 1. 页面清单

| # | 路由 | 页面 | 访问权限 |
|---|------|------|---------|
| P1 | `/login` | 登录页 | 公开；已登录访问时重定向到 `/` |
| P2 | `/` | 控制台占位首页 | 需登录；未登录访问时重定向到 `/login?from=<原路径>` |
| P3 | `*` | 未匹配路由 | 重定向到 `/`（若未登录则经 P2 落到 `/login`） |

## 2. 登录页（P1）规格

### 2.1 整体布局

- 桌面端（≥1024px）：**双栏**。左栏为深色品牌区（宽度 45%~50%），右栏为浅色表单区。
- 平板/移动端（<1024px）：单栏纵向堆叠，品牌区收窄为顶部横幅（高度 ≤ 200px），表单区占满宽度；表单内容最大宽度 400px 居中。
- 视口高度不足时（<640px），品牌区可折叠隐藏，优先保证表单可操作性。

### 2.2 左栏（深色品牌区）内容

| 元素 | 规格 |
|----|----|
| 背景 | 深色渐变（近黑蓝 `#0B1220` → `#111C33`），叠加细网格纹理与一处青蓝色径向光晕 |
| 品牌标识 | 产品名「RTS 搬运工」+ 英文副标 `RTS Task Orchestrator` |
| 一句话定位 | 「任务调度 · 链路监控」 |
| 链路示意 | 展示 `receive → transform → sink` 三段流转，带流动光点动画，表示任务流水线 |
| 服务状态 | 「● 服务正常」形式的健康状态指示 |
| 装饰 | 低透明度几何线条 / 圆点，不承载信息，不干扰右侧表单 |

### 2.3 右栏（浅色表单区）内容

| 元素 | 规格 |
|----|----|
| 标题 | 「欢迎回来」，副标题「登录以进入搬运工控制台」 |
| 用户名 | 输入框，`autocomplete="username"`，前置用户图标 |
| 密码 | 输入框，密码遮蔽 + 「显示/隐藏」切换按钮，`autocomplete="current-password"` |
| 记住我 | 复选框，勾选后凭证写入 `localStorage`，未勾选写入 `sessionStorage` |
| 忘记密码 | 文字链按钮，点击给出「请联系管理员重置」的轻提示（本次不实现找回流程） |
| 登录按钮 | 主按钮，全宽，提交中显示 loading 态（spinner + 禁用） |
| 演示账号提示 | 仅在 mock 模式展示，给出可用的测试账号与口令 |
| 页脚 | 版本号 / 版权信息，占位 |

### 2.4 表单校验规则

| 字段 | 规则 | 提示文案 |
|----|----|---------|
| 用户名 | 必填，去首尾空格后非空 | 请输入用户名 |
| 密码 | 必填，非空 | 请输入密码 |
| 通用 | 用户名/密码长度上限 64 字符 | 输入过长 |

- 校验时机：首次提交时全量校验；之后输入时实时清除该字段的错误。
- 错误呈现：字段下方红色文案 + 输入框红色边框 + `aria-invalid="true"` + `aria-describedby` 指向错误文案 id。

### 2.5 交互与状态

| 状态 | 表现 |
|----|----|
| 初始 | 表单可用，登录按钮为「登录」 |
| 提交中 | 按钮禁用并显示 spinner，文案变「登录中…」，输入框禁用 |
| 失败（服务端） | 表单顶部展示错误提示条（Alert 样式）：图标 + 服务端返回的中文消息；不丢失用户已输入的用户名；密码清空 |
| 成功 | 跳转 `from` 指定的页面（无 `from` 则跳 `/`），携带一次轻量 toast「登录成功」 |
| 记住登录态 | 刷新页面后守卫仍放行，首页展示当前用户信息 |

### 2.6 错误文案映射

| 服务端 code | 页面文案 |
|------------|---------|
| `INVALID_CREDENTIALS` | 用户名或密码错误 |
| `ACCOUNT_DISABLED` | 该账号已被停用，请联系管理员 |
| `ACCOUNT_LOCKED` | 账号已锁定，请稍后再试或联系管理员 |
| `RATE_LIMITED` | 尝试过于频繁，请稍后再试 |
| `VALIDATION_ERROR` | 提交信息有误，请检查后重试 |
| `NETWORK_ERROR` | 无法连接到服务器，请检查网络后重试 |
| `SERVER_ERROR` | 服务器开小差了，请稍后再试 |

## 3. 路由与守卫规格

- 路由表为显式配置，`/login` 与 `/` 分属 `public` 与 `protected` 两个分组。
- 守卫行为：
  1. 受保护页访问时若**无有效登录态** → 重定向 `/login?from=<当前完整路径（含 query）>`。
  2. 登录态存在但**已过期** → 清理凭证并按 1 处理。
  3. 已登录访问 `/login` → 重定向 `/`。
  4. 登录成功后 → 跳转到 `from`（必须是站内相对路径，防止开放重定向）；`from` 缺失或非法时跳 `/`。
- 登录态来源与优先级：`localStorage` → `sessionStorage`，读取时校验过期时间。
- 退出登录：清除两处存储的凭证与用户信息，跳转 `/login`。

## 4. 认证接口契约

统一前缀 `/api/v1`。响应体统一为 JSON；错误响应体固定为 `{ "code": <枚举>, "message": <中文提示> }`。

### 4.1 登录

```
POST /api/v1/auth/login
Content-Type: application/json

{
  "username": "admin",
  "password": "Admin@123",
  "remember": true
}
```

成功 `200`：

```json
{
  "token": "eyJhbGciOi...",
  "tokenType": "Bearer",
  "expiresAt": "2026-10-25T18:00:00Z",
  "user": {
    "id": "u-1001",
    "username": "admin",
    "displayName": "系统管理员",
    "roles": ["super_admin"]
  }
}
```

失败状态码：

| HTTP | code |
|-----|-----|
| 400 | `VALIDATION_ERROR` |
| 401 | `INVALID_CREDENTIALS` |
| 403 | `ACCOUNT_DISABLED` / `ACCOUNT_LOCKED` |
| 429 | `RATE_LIMITED` |
| 500 | `SERVER_ERROR` |
| —（网络异常） | `NETWORK_ERROR` |

### 4.2 会话恢复与登出

```
POST /api/v1/auth/logout      // 无请求体，携带 Authorization: Bearer <token>
```
成功返回 `204`。

会话恢复复用登录返回的 `token` + `expiresAt`，前端本地校验即可；后端如需强校验可另加 `GET /api/v1/auth/session`（本次不实现）。

### 4.3 Mock 与真实后端切换

- 前端定义 `AuthApi` 接口（`login` / `logout`），页面只依赖接口，不感知实现。
- 提供 `mockAuthApi` 实现：内置账号 `admin / Admin@123`（角色 `super_admin`）与 `operator / Operator@123`（角色 `operator`）；模拟 600ms 延迟；用户名或密码错误返回 `INVALID_CREDENTIALS`；账号不存在同样返回 `INVALID_CREDENTIALS`。
- 通过环境变量 `VITE_API_MODE=mock|real` 切换：`mock`（默认）走内置实现，`real` 走 `fetch` 真实请求（基础地址取 `VITE_API_BASE_URL`，默认 `/api/v1`）。
- 真实模式下请求头带 `Authorization: Bearer <token>`。

## 5. 设计令牌规格

- 主题令牌以 CSS 变量（`:root`）定义，由 Tailwind 主题引用。
- 语义色：品牌主色（青蓝 `#38BDF8` 系）、主文字、次文字、弱文字、边框、危险色、背景层级、圆角、阴影。
- 字体：系统字体栈（`system-ui` / `PingFang SC` / `Microsoft YaHei` / `sans-serif`），标题与正文共用，靠字重与字号拉开层级。
- 圆角基准 8px（卡片 12px），输入框 8px。
- 明暗：本次仅提供单一主题（左侧深色 + 右侧浅色），不提供主题切换开关；`color-scheme` 声明为 `light` 以避免浏览器原生控件在暗色背景区反色异常。

---

## 6. 无障碍规格

- 表单控件均有 `<label>`（视觉隐藏亦可，但需可关联）。
- 错误提示使用 `role="alert"`；加载状态按钮带 `aria-busy`。
- 焦点环可见（2px 品牌色描边 + 偏移），不允许 `outline: none` 了事。
- 全流程键盘可达，Tab 顺序符合视觉顺序。
- 装饰性图形 `aria-hidden="true"`。
- 正文对比度 ≥ 4.5:1，大字号 ≥ 3:1。
